# MB01 — source intake and real backend evaluation

Status: IN_PROGRESS. This is the first implementation slice of the accepted six-batch roadmap, not completion of MB01.

## Scope and provenance
Upstream: YoshCasaster/Ninjasage-PrivateServer-community at a53f074aaa0690398db947205956ffb97d5671aa. Root MIT notice (2026 mardhiahnetwork) is retained for the imported server text. Existing third-party headers are preserved. This review does not establish rights in the game client, brand, art, sound or databases; those are excluded. No relationship to Ninja Zero/KotaGames is asserted.

The importer selects server PHP/config/migrations/Blade files, Composer manifests and entrypoints; verifies Git blobs; rejects high-confidence secret markers; and emits per-file original/current hashes plus an inventory summary of excluded component sizes. This is not a complete secret or security audit.

## Deliberate adaptations
- B00's eight-file ceiling is replaced by source hygiene checks.
- Hardcoded-email admin exemptions are removed in favor of explicit roles.
- AMF/game/clan/crew routes and background schedules remain disabled.
- Community seeders, setup hooks and default accounts are never run.
- UI and admin behavior reuse the existing Filament panel and prior WebFirst operations page.
- Composer installation disables scripts/plugins; package discovery is invoked explicitly in read-only CI. Dependency audit and full vulnerability remediation remain required before a public runtime.

## Evidence gates
1. Intake succeeds on pinned source and publishes a review branch only.
2. MySQL migrations and Filament auth/authorization/settings tests pass.
3. Browser UI, persistence across restart, and user-accessible private preview still need separate verification. Passing CI is not a public website or proof of gameplay.

## Rollback
Before merge, close the PR. After merge, revert the implementation commits. CI databases are disposable and contain only synthetic test accounts. There is no production database or player data to restore.

## Cost boundary
Standard Ubuntu jobs only, no artifacts, persistent cache, paid runners, Codespaces creation, hosting purchase or public deployment. The short intake job has contents:write only to publish a new review branch and does not execute upstream code; application execution is read-only in a separate job. No PAT is requested.
